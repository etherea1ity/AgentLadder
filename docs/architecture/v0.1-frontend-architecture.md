# v0.1 Frontend Architecture

## Stack

- React + TypeScript + Vite.
- Plain CSS modules/global CSS for v0.1 to avoid dependency sprawl.
- Browser `EventSource` for SSE.

## Component tree

```text
AppShell
├── Sidebar
├── ChatWorkspace
│   ├── TopPathBar
│   ├── EmptyHome
│   ├── MessageList
│   ├── AssistantMessage
│   │   ├── ThinkingInlineBar
│   │   └── AssistantContent
│   └── ChatInput
└── RunMargin
```

## State model

TypeScript entities: `Session`, `Message`, `Run`, `RunEvent`, `UIState`. Single source of truth lives in app state; components receive data via props.

Key invariants:

- `assistantMessage.run_id = run.run_id`.
- `selectedRunId` controls Run Margin.
- session switch clears selected run.
- `answer_delta` appends content but is not rendered as a timeline row.

## API client

- `createSession()`
- `listSessions()`
- `getSession(id)`
- `renameSession(id, title)`
- `deleteSession(id)`
- `createRun(session_id, question)`
- `getRun(id)`
- `cancelRun(id)`
- `subscribeRunEvents(run_id, handlers)`

## SSE handling

- Open EventSource after `POST /api/runs` returns.
- Replay historical events comes from backend stream.
- On terminal event, close EventSource.
- On unexpected close before terminal event, call `GET /api/runs/{run_id}`.

## Accessibility

- ThinkingInlineBar is a real button.
- Use `aria-expanded`, `aria-controls`, and descriptive label.
- ESC closes Run Margin on overlay/drawer layouts.
- Focus returns to triggering button after close.
- Keyboard supports Enter send and Shift+Enter newline.
