# v0.1 Agent Core Run Lifecycle

## Principle

Core stays independent from frontend and FastAPI. It exposes contracts and LLM/runtime helpers; API owns sessions, messages, app run records, SSE, and app storage.

## Existing contracts

- `AskState`: input state.
- `AnswerState`: output state.
- `RunLog`: observability state.
- `JsonlTracer`: trace writer.
- `DashScopeClient`: OpenAI-compatible LLM provider.

## Required additions

- Streaming support from the LLM layer.
- Run event type for app/API lifecycle.
- A UI-agnostic service path that can emit safe events while building `AskState`, `AnswerState`, and `RunLog`.

## Lifecycle

1. Create `AskState`.
2. Emit `run_created` from API layer.
3. Emit `thinking_started`.
4. Emit `llm_call_started`.
5. Stream model answer deltas.
6. Build `AnswerState` from accumulated answer.
7. Build `RunLog` with latency/tokens/error.
8. Save JSONL trace.
9. Emit `llm_call_completed` and `run_completed`.

## Safety

Do not expose or store raw chain-of-thought/reasoning content for UI. DashScope thinking-related fields are ignored for visible output in v0.1.

## Testing provider

Production runtime uses the real DashScope provider. Tests may define local deterministic providers, but app code should not ship an alternate response provider.
