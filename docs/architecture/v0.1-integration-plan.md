# v0.1 Integration Plan

## Layout decision

Use a single repository with reusable Python core under `src/agent_ladder`, backend app under `apps/api`, and frontend app under `apps/web`.

## Dev commands

- Install Python: `python3 -m pip install -e ".[dev]"`
- Run API: `uvicorn apps.api.main:app --reload --port 8000`
- Run web: `cd apps/web && npm install && npm run dev`
- Test Python: `pytest`
- Build frontend: `cd apps/web && npm run build`
- E2E/UI: `cd apps/web && npm run test:e2e`

## Integration sequence

1. Backend starts and replays JSONL state.
2. Frontend loads session list.
3. New Chat leaves `activeSessionId = null`.
4. Send question creates session if needed, then creates run.
5. Frontend subscribes to run SSE.
6. Answer deltas update assistant content.
7. Run completed updates Run Margin/log/trace.
8. Delete session calls backend and removes UI state.
9. Refresh reloads non-deleted session list.

## Live demo acceptance

The demo must show: New Chat, ask `What is an AI Agent?`, streaming answer, thinking bar updates, click thinking opens Run Margin, completed summary/tokens/trace visible, delete conversation, refresh shows deleted session absent.
