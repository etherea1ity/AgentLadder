# v0.1 Minimal Agent Freeze Report

## 1. Goal

Deliver a minimal full-stack Agent Ladder app where a normal question becomes an observable run and JSONL trace.

## 2. What was implemented

- Core contracts: `AskState`, `AnswerState`, `RunLog`.
- DashScope/OpenAI-compatible LLM provider with streaming support.
- JSONL tracer for `data/traces/runs.jsonl`.
- FastAPI backend under `apps/api` with sessions, messages, runs, run events, SSE, cancellation, rename, and soft delete.
- JSONL app storage under `data/app` with replay-on-read semantics.
- React/Vite frontend under `apps/web`.
- Quiet paper/ink UI matching the v0.1 reference direction: sidebar, chat workspace, ThinkingInlineBar, and selected-run Run Margin.
- Inline rename/delete popovers for conversation management.
- Documentation for product interaction, visual system, frontend architecture, backend API/storage, core run lifecycle, integration, audit, and chapter narrative.
- Python, frontend component, and E2E-style tests.

## 5. State evolution

`AskState` is the input, `AnswerState` is the output, `RunLog` is observability, and app-level `RunEvent` drives the UI timeline and streaming content.

## 6. AnswerFrame evolution

No AnswerFrame in v0.1. It begins in the RAG chapter.

## 7. How to run

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -e ".[dev]"
cd apps/web && npm install && cd ../..

# terminal 1
uvicorn apps.api.main:app --reload --port 8000

# terminal 2
cd apps/web
npm run dev
```

Open `http://127.0.0.1:5173`.

The root `start.ps1` path uses the real DashScope/Qwen provider.

Validated flow:

1. Created a session.
2. Asked `请用一句话介绍你是谁。` through `POST /api/runs`.
3. Consumed SSE stream.
4. Observed `answer_delta` and terminal completion.
5. Confirmed completed run with `model=qwen3.6-plus`, `trace_saved=true`, and persisted events.
6. Confirmed frontend dev server returned the Agent Ladder HTML shell.
7. Confirmed Windows PowerShell can reach both `http://127.0.0.1:5173` and `http://127.0.0.1:8000/api/health`.

## 10. Textual UI walkthrough

- Default view: warm paper sidebar and quiet main home with “From Prompt to Policy” and “A question becomes a trace.”
- Sending a question creates a lazy session, adds a user message, and shows an assistant placeholder with `Queued` then `Thinking/Writing` status.
- The assistant answer streams into the chat.
- Clicking the ThinkingInlineBar opens the right Run Margin for only that run.
- Completed Run Margin shows summary, timeline, run log, and collapsible/copyable JSON trace.
- Deleting the active conversation removes it from UI and backend visible session list, then returns to empty home.

## 11. Known limitations

- Local JSONL persistence only.
- Cancellation is best-effort when the upstream provider cannot be interrupted immediately.
- No login or multi-user isolation.
- No RAG, memory, research, MCP, eval, or RL.
- No Playwright screenshot artifact in this freeze; textual walkthrough and component/E2E tests are the current visual evidence.
