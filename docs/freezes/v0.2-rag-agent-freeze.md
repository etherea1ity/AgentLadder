# v0.2 RAG Agent Freeze

Branch: `v0.2-rag-agent`

## Freeze claim

v0.2 teaches and implements the first local RAG loop for Klara:

```text
Question
→ Intent Router
→ Dense Retrieval + BM25
→ Hybrid Retrieval
→ Reranking
→ Context Builder
→ Klara Writer
→ AnswerFrameV1
→ Run Chain / JSONL Trace
```

## Implemented

- Local Markdown + metadata knowledge library.
- Document and chunk contracts.
- Overlap chunker.
- IndexRecord layer.
- DashScope embedding adapter.
- Local JSONL index store.
- Dense cosine retrieval.
- BM25 keyword retrieval.
- Weighted hybrid fusion.
- Rule-based reranker.
- Context builder.
- LLM JSON intent router with deterministic fallback.
- Lightweight `AnswerFrameV1` with question, answer, and evidence.
- SourceCard/Citation contracts.
- API run lifecycle module events.
- Frontend Run Chain cards.
- Klara v0.2 UI and screenshots.

## Verification

## Known limitations

- Local JSONL index only.
- No production vector database yet.
- No cross-encoder or LLM reranker yet.
- No citation verifier or claim-level citation checking yet.
- No query rewrite, retrieval planner, evidence grader, or agentic state machine yet.
- `KlaraAgent` orchestration still lives in `core/runtime`; v0.3 should move it to an agent/RAG runtime boundary before adding loops.

## Next branch

`v0.3-agentic-rag` should focus on turning simple RAG into Agentic RAG:

```text
retrieve → read → select evidence → write → verify
```
