# v0.3 Agentic RAG Freeze

Branch: `v0.3-agentic-rag`

## 1. Goal

Upgrade Klara from fixed Chapter 2 RAG into a controlled local evidence-search runtime.

## 2. What This Chapter Builds

- Controlled Agentic RAG workflow.
- Request normalization and language control.
- Evidence search planning with candidate budgets.
- Local paper corpus interface and fixtures.
- Search/fetch providers for paper metadata, overviews, chunks, and visuals.
- Multi-path retrieval with RRF, paper-level dedup, diversity rerank, and weak-retrieval rewrite once.
- EvidencePack writer boundary.
- AnswerFrameV2.
- Citation/evidence/visual/language verification.
- DecisionRecords in v0.3 JSONL trace.
- `ask-agentic` CLI.
- Real FastAPI endpoint for Chapter 3 fullstack demos: `POST /api/runs`.
- React/Vite Chapter 3 page at `/`, including source cards, visual source cards, run info, search plan, retrieval attempts, and trace path.

## 3. New Concepts

Controlled runtime, typed worker contracts, search/fetch abstraction, Figure-aware RAG, EvidencePack, DecisionTrace, bounded failure policy.

## 4. New Contracts

`RequestSpec`, `LanguagePlan`, `OutputStyleSpec`, `AnswerRequirement`, `RouteState`, `SubQuestion`, `CapabilitySpec`, `WorkerAgentSpec`, `SearchProviderSpec`, `SearchRequest`, `SearchHit`, `FetchRequest`, `FetchResult`, `SearchUnit`, `EvidenceSearchPlan`, `RetrievalAttempt`, `PaperCard`, `VisualElement`, `EvidenceItem`, `EvidencePack`, `AnswerFrameV2`, `VerificationResult`, `DecisionRecord`, `BudgetState`, `FailurePolicy`, `WorkflowState`.

## 5. State Evolution

`AskState` and `AnswerState` remain unchanged. Chapter 3 adds `RequestSpec` and `WorkflowState` around them rather than replacing them.

## 6. AnswerFrame Evolution

`AnswerFrameV1` remains question/answer/evidence for Chapter 2. `AnswerFrameV2` adds answer mode, claims, sub-questions, citations, source cards, evidence items, visual sources, rendered assets, and final text.

## 7. How to Run

```bash
python -m agent_ladder.app.cli.main ask-agentic "给我 10 篇 Agentic RAG 相关论文，并按路线分类"
python -m agent_ladder.app.cli.main ask-agentic "Explain figure aware RAG in Chinese, include figure"
python -m agent_ladder.app.cli.main ask-agentic "给我 10 篇 Agentic RAG 相关论文，并按路线分类" --paper-root data/papers
```

Fullstack:

cd apps/web && npm run dev -- --host 127.0.0.1 --port 5123

## 9. Known Limitations

- Real local corpus is supported via `--paper-root data/papers`, but PDF download/cleaning remains outside runtime.
- Dense providers are stable interfaces but simple/mock in behavior where vectors are absent.
- Caption-based visual retrieval only.
- Web UI is synchronous/fullstack for bounded local research; streaming Chapter 3 progress can be added later without changing the runtime boundary.
- Answer writer is deterministic teaching logic, not a production LLM writer.
