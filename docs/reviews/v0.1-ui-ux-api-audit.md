# v0.1 UI / UX / API Audit

## Result

**Status: PASS** for the v0.1 Minimal Agent webapp scope.

The implementation keeps the product to Ask → Answer → Trace, with no RAG, memory, research, MCP, eval, RL, auth, billing, database migration, file upload, or graph visualization.

## Pass / fail checklist

| Area | Result | Evidence |
| --- | --- | --- |
| Sidebar stays minimal | PASS | Sidebar contains brand, subtitle, v0.1 Minimal Agent, New Chat, Today, Earlier, small footer. |
| Empty home is quiet and English-only | PASS | `EmptyHome` shows ladder mark, From Prompt to Policy, “A question becomes a trace.”, input, subtle v0.1 hint. |
| Run Margin default hidden | PASS | `RunMargin` renders only when `runMarginOpen && selectedRunId`. |
| Run Margin selected-run only | PASS | `RunMargin` receives only `selectedRun`; switching sessions clears selected run. |
| ThinkingInlineBar opens/switches Run Margin | PASS | Button sets `selectedRunId` and `runMarginOpen`, does not auto-open on send. |
| No raw chain-of-thought shown | PASS | DashScope provider ignores `reasoning_content`; tests assert no chain-of-thought text in ThinkingInlineBar. |
| `answer_delta` does not flood timeline | PASS | UI aggregates streaming chars; timeline filters out per-token deltas. |
| Completed-only trace/log detail | PASS | Running view hides JSON/tokens; completed view shows summary/log/trace toggle. |
| Delete calls backend | PASS | `DELETE /api/sessions/{id}` soft-deletes; UI removes session and active session resets. |
| Refresh hides deleted sessions | PASS | Real smoke validated deleted session absent from `GET /api/sessions`. |
| SSE stream and replay | PASS | API test and real smoke saw `run_created`, `answer_delta`, `run_completed`. |
| Frontend/backend/core separation | PASS | Core in `src/agent_ladder`, API in `apps/api`, web in `apps/web`. |
| Accessibility basics | PASS | ThinkingInlineBar is button with `aria-expanded`, `aria-controls`, and label. |
| Warm paper visual direction | PASS | CSS tokens match paper/ink/margin palette; no neon/gradient/dashboard UI. |

## Critical issues

None open for v0.1 freeze.

## Must-fix before implementation

All pre-implementation must-fix items were resolved:

- Raw reasoning is neither displayed nor stored for UI.
- Delete calls backend and hides deleted sessions after refresh.
- Answer deltas do not render as individual Run Margin timeline rows.
- Run Margin does not auto-open on send.
- Frontend build/typecheck passes.
- Backend API, storage replay/delete, SSE, run lifecycle, ThinkingInlineBar, and E2E flows have tests.
