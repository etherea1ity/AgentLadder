# v0.1 Current State Review

## Objective

Build Agent Ladder v0.1 as a full-stack minimal-agent learning webapp: a warm paper chat UI, backend sessions/messages/runs/events, SSE answer streaming, JSONL persistence, Run Margin, tests, docs, and freeze report.

## Existing branch

- Current branch: `v0.1-minimal-agent`
- Existing core package path: `src/agent_ladder/`
- Existing local config: `.env` is ignored by git; `.env.example` is safe template.

## Existing files

- `configs/default.yaml`: DashScope provider config, trace path.
- `pyproject.toml`: initial Python package config.
- `src/agent_ladder/core/contracts/ask.py`: `AskState`.
- `src/agent_ladder/core/contracts/answer.py`: `AnswerState`.
- `src/agent_ladder/core/contracts/run.py`: `RunLog`.
- `src/agent_ladder/core/runtime/minimal_agent.py`: minimal non-streaming agent runtime.
- `src/agent_ladder/core/tracing/jsonl_tracer.py`: trace writer.
- `src/agent_ladder/llm/base.py`: LLM interface and response type.
- `src/agent_ladder/llm/providers/dashscope.py`: DashScope OpenAI-compatible provider.
- `.codex/skills/agent-ladder-webapp/`: project-local skill and reference spec.

## Missing pieces

- Full-stack `apps/api` backend.
- React/Vite `apps/web` frontend.
- App-level storage for sessions/messages/runs/events under `data/app`.
- Run event contract and SSE delivery.
- Backend-backed rename/delete/cancel.
- Frontend warm paper UI matching the supplied image.
- Tests for contracts/storage/API/SSE/frontend/e2e.
- Product, architecture, audit, chapter, and freeze docs.

## Scope guard

v0.1 must not add RAG, memory, research, MCP, eval dashboard, RL, auth, upload, complex settings, graph visualization, or raw chain-of-thought display.

## Implementation stance

Preserve `src/agent_ladder/` as reusable core. Add backend/frontend around it:

- `apps/api` for FastAPI.
- `apps/web` for React + TypeScript + Vite.
- `data/app` for JSONL app state.
- `data/traces` for trace JSONL.
