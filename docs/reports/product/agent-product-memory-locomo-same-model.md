## 边界

- 所有系统使用同一 100 题、同一 DeepSeek 模型、同一提示词和相同输出上限。
- F1 使用固定的 LoCoMo 类别与词元规则；没有用另一个模型替代官方确定性分数。
- semantic_recency 只是 Klara 本地消融，不冒充 Mem0；Mem0 官方流水线单独执行和报告。
- 本阶段没有训练，也没有使用本机 GPU。
