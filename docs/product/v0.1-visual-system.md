# v0.1 Visual System

## Direction

Quiet, paper-like, ink, margin notes, minimal, philosophical, editorial, warm neutral, low contrast, state-aware.

## Reference image interpretation

The supplied UI image is the target: warm left sidebar, centered chat, calm ThinkingInlineBar, bottom input, and right Run Margin shown only after selecting a run.

## Typography

- UI: system sans stack.
- Hero and answer text may use `Georgia, ui-serif, serif` for the editorial feel.
- Labels and Run Margin use smaller sans text.
- Avoid tiny text below 12px.

## Layout dimensions

- Sidebar: 260px desktop.
- Run Margin: 360px desktop large.
- Message column: max-width 760px.
- Input: aligned to message column; bottom fixed/sticky.

## Component states

### ThinkingInlineBar

- queued: muted hollow dot, no pulse.
- thinking: green breathing dot.
- streaming: green moving/pulse dot and answer caret.
- completed: quiet check, static.
- failed: muted clay/red, no flashing.
- cancelled: muted stopped state.

### Run Margin

- Running: live status and aggregate activity only.
- Completed: summary, timeline, run log, collapsed JSON.
- Failed: stage, error, Retry, Copy error, Close.
- Cancelled: partial answer note and cancellation timeline.

## Motion

- Thinking breathing: 1.4s ease-in-out infinite.
- Run Margin slide/fade: 180ms.
- Timeline rows fade in subtly.
- No spinners, bouncing loaders, 3D, or large transitions.

## Responsive

- >=1280px: Run Margin layout-pushes main.
- 1024-1279px: Run Margin overlays as right sheet; no backdrop.
- <900px: full-height drawer or bottom sheet.

## Do / Don't

Do: warm paper, calm ink, subtle borders, spacious messages, state clarity.

Don't: neon, dashboards, dark enterprise sidebar, heavy gradients, dense cards, raw JSON on the main page, raw chain-of-thought.
