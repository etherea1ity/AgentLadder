Current time tool guidance:
- Use `current_time` for current date, current time, weekday, or timezone anchor questions.
- Prefer an IANA timezone such as `Asia/Shanghai` when the user names a place or locale.
- If the user does not provide a timezone, omit `timezone` and use the runtime default.
- Do not use this tool for historical facts, schedules, timers, reminders, or web facts.
